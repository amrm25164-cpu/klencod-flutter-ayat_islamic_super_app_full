# آيات | AYAT — Complete Islamic Super App

تطبيق **آيات** الإسلامي الشامل والمكتمل الأكواد مبني باستخدام **Flutter** و **Clean Architecture**.

## المميزات المكتملة في هذا الاصدار (Full Codebase):
1. **القرآن الكريم والتفاسير**: استعراض السور، حفظ المواضع والعلامات المرجعية عبر Drift DB.
2. **أوقات الصلاة والآذان**: التحديد التلقائي/اليدوي مع خوارزميات الحساب الدقيقة وتنبيهات الأذان.
3. **بوصلة القبلة**: التوجيه الحقيقي نحو الكعبة المشرفة باستخدام حساس المغناطيسية (`sensors_plus`) والموقع.
4. **الأذكار والسبحة الرقمية**: تسبيح تفاعلي مع العداد وميزات الاهتزاز وحفظ الجلسات.
5. **موسوعة الحديث الشريف**: تصفح صحيح البخاري ومسلم والسنن مع نظام البحث المتطور.
6. **مشغل الصوتيات والمقاطع**: دعم تشغيل التلاوات في الخلفية للعديد من القراء المعتمدين.
7. **رفيق آيات**: المساعد الذكي للإجابة عن الأسئلة الإسلامية والعلوم الشرعية.
8. **المكتبة الإسلامية والتقويم الهجري**: تصفح الكتب والتقويم مع تحديد الأعياد والمناسبات.
